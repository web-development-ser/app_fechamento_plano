Instruções do Projeto — Claude Code
Objetivo
Desenvolver uma aplicação web utilizando Python, Flask, HTML, CSS, JavaScript e PostgreSQL.
Responsabilidades
•	Respeitar as especificações documentadas em SPEC.md.
•	Seguir a arquitetura documentada em ARCHITECTURE.md.
•	Implementar funcionalidades de forma incremental.
•	Não modificar regras de negócio sem autorização.
•	Manter o código organizado e modular.
•	Criar testes para cada funcionalidade implementada.
•	Executar testes antes de considerar uma tarefa concluída.
Regras técnicas
1.	Utilizar Flask para o backend.
2.	Utilizar PostgreSQL como banco de dados.
3.	Utilizar HTML, CSS e JavaScript no frontend.
4.	Centralizar configurações no arquivo .env.
5.	Nunca expor credenciais no código ou nos logs.
6.	Utilizar consultas parametrizadas.
7.	Implementar tratamento de exceções.
8.	Validar arquivos e dados recebidos.
9.	Evitar duplicidade de registros.
10.	Registrar alterações relevantes para rastreabilidade.
Metodologia obrigatória
Para cada implementação:
1.	Analisar a especificação.
2.	Identificar arquivos envolvidos.
3.	Implementar uma pequena funcionalidade.
4.	Criar ou atualizar testes.
5.	Executar os testes.
6.	Corrigir eventuais problemas.
7.	Documentar o resultado.
Não implementar várias funcionalidades grandes sem validação intermediária.
Regra de segurança
Não executar operações destrutivas no banco de dados sem autorização explícita.
Não sobrescrever arquivos existentes sem analisar seu conteúdo.
Critério de conclusão
Uma funcionalidade somente será considerada concluída quando estiver implementada, testada e documentada.
