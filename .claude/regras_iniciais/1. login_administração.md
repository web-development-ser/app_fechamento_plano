    Interface de Entrada 1 – Autenticação e Gerenciamento de Usuários
1. Tela de Login – Acesso ao Sistema

Desenvolver uma tela de autenticação para permitir que os usuários acessem o sistema por meio de credenciais individuais.

A tela deverá conter os seguintes campos:

Usuário: identificação única do usuário cadastrado.
Senha: senha pessoal para autenticação, com opção de visualizar ou ocultar os caracteres digitados.

O sistema deverá validar as credenciais informadas antes de permitir o acesso.

2. Identificação e Registro do Usuário

Cada usuário deverá possuir uma conta individual. Todos os registros, operações e informações inseridas no sistema deverão ser automaticamente vinculados ao usuário que realizou o login.

O sistema deverá registrar automaticamente:

Identificação do usuário responsável pelo registro.
Nome do usuário.
Data e horário da operação, quando aplicável.

Essa funcionalidade permitirá rastrear quem realizou cada inclusão, alteração ou operação dentro do sistema, garantindo maior controle e rastreabilidade das informações.

3. Cadastro de Usuários e Credenciais

Criar uma tabela para armazenar os dados de acesso dos usuários, contendo os seguintes campos:

Campo	Descrição
ID	Identificador único do usuário.
Nome	Nome completo do usuário.
Usuário	Identificação única utilizada para login.
Senha	Senha armazenada de forma segura, utilizando hash criptográfico.
Perfil	Nível de permissão do usuário (Administrador ou Usuário).
Status	Indica se o usuário está ativo ou inativo.
4. Interface Administrativa – Gerenciamento de Usuários

Desenvolver uma interface exclusiva para administradores, permitindo o gerenciamento das contas cadastradas.

O administrador deverá conseguir:

Visualizar a lista de usuários cadastrados.
Cadastrar novos usuários.
Editar nome e identificação dos usuários.
Redefinir a senha de um usuário que tenha perdido o acesso.
Ativar ou desativar contas.
Consultar o perfil e o status de cada usuário.
5. Recuperação de Acesso

Caso um usuário perca ou esqueça sua senha, deverá existir um procedimento para recuperação de acesso por meio do administrador.

O administrador poderá realizar a redefinição da senha, permitindo que o usuário volte a acessar o sistema com uma nova credencial.

Por segurança, o sistema nunca deverá exibir ou permitir consultar a senha original de qualquer usuário.

6. Controle de Permissões e Segurança
Somente administradores poderão acessar a interface de gerenciamento de usuários.
Usuários comuns não poderão visualizar, editar ou gerenciar as credenciais de outros usuários.
Cada usuário deverá ter sua identidade preservada durante toda a sessão.
As senhas deverão ser armazenadas utilizando hash seguro, nunca em texto puro.
O sistema deverá impedir o acesso de usuários inativos.
Todas as operações deverão manter a identificação do usuário responsável.
7. Resultado Esperado

Implementar um sistema de autenticação individualizado, com controle administrativo de usuários e senhas, garantindo que todas as informações registradas sejam vinculadas ao respectivo usuário responsável.

O objetivo é proporcionar segurança, organização, rastreabilidade e controle sobre as atividades realizadas dentro do sistema.
