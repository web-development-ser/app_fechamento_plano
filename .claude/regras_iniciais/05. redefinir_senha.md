## 8. Redefinir Senha

Implementar ou ajustar a funcionalidade de redefinição de senha, exigindo a validação das credenciais atuais do usuário antes de permitir a alteração.

### 8.1. Campos da interface

- **Usuário:** identificação do usuário.
- **Senha Atual:** senha atualmente cadastrada.
- **Nova Senha:** nova senha desejada.

### 8.2. Regras de funcionamento

- O usuário deverá informar seu nome de usuário.
- Deverá informar a senha atual para validar sua identidade.
- Deverá preencher a nova senha desejada.
- O sistema deverá validar se o usuário e a senha atual correspondem às credenciais cadastradas.
- Caso as credenciais estejam incorretas, a alteração deverá ser bloqueada e uma mensagem de erro deverá ser apresentada.
- Caso a validação seja aprovada, o sistema deverá atualizar a senha.
- A nova senha deverá substituir a senha anterior imediatamente após a confirmação.

### 8.3. Critérios de aceite

- [ ] Sistema exige o preenchimento do usuário.
- [ ] Sistema exige a senha atual.
- [ ] Sistema exige o preenchimento da nova senha.
- [ ] Sistema valida as credenciais atuais antes de permitir a alteração.
- [ ] Sistema bloqueia alterações com credenciais inválidas.
- [ ] Sistema confirma a alteração quando realizada com sucesso.
- [ ] Nova senha passa a ser utilizada nos próximos acessos.
- [ ] Senhas devem ser armazenadas de forma segura, utilizando hash apropriado, nunca em texto puro.
