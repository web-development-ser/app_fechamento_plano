# Especificação Funcional – Atualização da Aplicação

## 1. Mapeamentos de Programas Interrompidos

Criar uma nova interface para registro manual de programas interrompidos, priorizando a utilização em dispositivos móveis (mobile-first).

### 1.1. Campos da interface

**Campos preenchidos pelo usuário:**
- **Programa:** identificação do programa.
- **Documento:** número ou identificação do documento.
- **Fila + Posição:** seleção de uma vaga disponível:
  - M01 até M20;
  - P01 até P20;
  - S01 até S20.

**Campos preenchidos automaticamente pelo sistema:**
- **Data e Hora de Registro:** data e horário do cadastro.
- **Turno:** identificação automática conforme o horário:
  - 1º turno: 05:25 até 15:15.
  - 2º turno: 15:15 até 00:47.
- **Nome do Usuário:** usuário responsável pelo registro.

### 1.2. Regras de funcionamento

- Permitir o preenchimento manual dos dados.
- Disponibilizar somente vagas livres para seleção.
- Após o registro, reservar a vaga selecionada.
- Ao realizar o atendimento correspondente, liberar automaticamente a vaga reservada.

## 2. Integração com a interface "Atendimento ao Item"

Implementar uma integração entre os dados de **Mapeamentos de Programas Interrompidos** e a interface de **Atendimento ao Item**, utilizando uma lógica semelhante ao PROCV/PROCX.

### 2.1. Vinculação automática de dados

| Mapeamentos de Programas Interrompidos | Atendimento ao Item |
|---|---|
| Programa | Prog. Orig. |
| Documento | Documento |

O sistema deverá localizar os registros correspondentes e disponibilizar os dados automaticamente no atendimento.

### 2.2. Liberação de vaga

- Ao identificar e realizar o atendimento de um registro vinculado, o sistema deverá liberar automaticamente a vaga anteriormente reservada.
- A vaga deverá voltar a ficar disponível para novos mapeamentos.

## 3. Ajustes na interface de edição do Atendimento

| Campo | Alteração |
|---|---|
| Resp. TS7 | Alterar para campo de texto livre, permitindo preenchimento manual do nome do responsável. Exemplo: "sergio". |
| Loc. TEGAD | Receber automaticamente a localização registrada na interface de Mapeamentos de Programas Interrompidos. O campo deverá ser somente leitura, sem possibilidade de edição manual. |

## 4. Interface de Importação

Ajustar a interface de importação para aceitar os seguintes formatos: `.xlsx`, `.csv`.

### 4.1. Pré-visualização dos dados

Disponibilizar, preferencialmente na própria interface, uma opção para visualizar os dados importados antes ou após a importação.

**Sugestão de implementação:**
- Criar um botão **"Visualizar Prévia"**.
- Exibir os dados em formato de tabela.
- Permitir a conferência das informações antes de concluir a importação.

## 5. Requisitos gerais

- Priorizar a experiência mobile na nova interface de mapeamentos.
- Automatizar o preenchimento dos campos de sistema.
- Evitar duplicidade de reservas de vagas.
- Garantir a sincronização entre mapeamentos e atendimentos.
- Garantir a liberação automática das vagas após o atendimento.
- Manter a integridade dos dados durante importações e atualizações.

## 6. Critérios de aceite

- [ ] Usuário consegue cadastrar programas interrompidos pelo celular.
- [ ] Sistema disponibiliza e reserva vagas conforme a seleção.
- [ ] Data, hora, turno e usuário são registrados automaticamente.
- [ ] Atendimento consegue localizar os dados do mapeamento correspondente.
- [ ] Vaga é liberada após o atendimento.
- [ ] Resp. TS7 permite preenchimento manual.
- [ ] Loc. TEGAD é preenchido automaticamente e não permite edição.
- [ ] Importação aceita arquivos XLSX e CSV.
- [ ] Interface disponibiliza pré-visualização dos dados importados.

## 7. Observações para desenvolvimento

- Definir a regra de identificação única do vínculo entre Programa e Documento.
- Definir o comportamento para registros duplicados.
- Definir o comportamento para atendimentos sem mapeamento correspondente.
- Definir como tratar os horários de transição dos turnos (15:15 e 00:47), evitando ambiguidades.
