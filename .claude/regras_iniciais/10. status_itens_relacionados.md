Spec — Atualização da interface de atendimento
Objetivo: Permitir que o usuário defina se a alteração de status deve ser aplicada somente ao item atual ou a todos os itens relacionados pelo mesmo programa e documento.
1. Gatilho
•    Ao clicar em Salvar durante o atendimento de um item, abrir um modal.
•    O sistema deve buscar outros itens que possuam o mesmo programa + documento do item atual.
2. Modal de confirmação
Exibir uma mensagem informando que existem outros itens relacionados e perguntar:
"A alteração de status deve ser aplicada somente a este item ou a todos os itens relacionados?"
O modal deve apresentar as seguintes opções:
•    Ver esses itens: permite visualizar os demais itens encontrados.
•    Somente este item: salva a alteração de status apenas no item atual.
•    Todos os itens: aplica o status selecionado a todos os itens encontrados com o mesmo "programa orig + documento".
4. Regras de negócio
•    A correlação deve considerar a combinação de programa + documento.
•    A alteração deve respeitar a escolha do usuário.
•    Se escolher somente este item, apenas o item atual terá seu status atualizado.
•    Se escolher todos, todos os itens encontrados terão o mesmo status selecionado no atendimento atual.
•    Itens sem correspondência não devem ser afetados.
•    Se não houver outros itens relacionados, salvar normalmente, sem exibir o modal.
5. Resultado esperado
Garantir que o atendimento permita atualizar individualmente ou em lote os status de itens relacionados, reduzindo operações repetitivas e evitando inconsistências.
